3. Account Builder (accountBuilder.js)

Groups parsed records by customer_account name, then calls buildAccountState(customer, funnel, closeLost, quotes, services, locations) per account.
buildAccountState(customer, funnel, closeLost, quotes, services, locations) INPUTS (per account): customer = 1 row from customers.csv (or aggregated if multi-row) funnel = all funnel.csv rows matching this account name closeLost = all close_lost.csv rows matching this account quotes = all quotes.csv rows services = all services.csv rows locations = all locations.csv rows STAGE NORMALIZATION: "Closed Won", "closed-won", "Accepted", "5 - Accepted" → "closed won" "Closed Lost", "Close Lost" → "closed lost" "1 - Discover", contains "discover" → "Discover" "2 - Design", contains "design" → "Design" "3 - Propose", contains "propose" → "Propose" "4 - Negotiate", contains "negotiate" → "Negotiate" COMPUTED FIELDS: totalARR = customer.total_brr (from customers.csv ONLY) totalMRR = totalARR / 12 activePipeline = funnel WHERE stage NOT IN [closed won, closed lost, ''] pipelineMRR = SUM(activePipeline.mrr) closedWon = funnel WHERE normalizeStage(stage) = 'closed won' wonDeals = closedWon WHERE mrr >= 0 churnDeals = closedWon WHERE mrr < 0 (negative re-rates) winRate = wonDeals / (wonDeals + closeLost) riskScore = 0..100 composite (silent days + losses + churn + disconnects + velocity) nrr = totalMRR / (totalMRR + downgradeMRR + disconnectMRR) OUTPUT ARRAYS: funnel_deals = activePipeline (open deals only) → becomes acc.active_deals funnel_closed = closedWon + closeLost from funnel.csv → SOURCE OF TRUTH for bookings Each deal: { product, mrr, stage, type, close, rep, opportunity_id, sales_channel, created, forecast_category, major_project } historical_deals = same as funnel_closed → modeling/predictions ONLY

4. Hooks: useLocalData.js / useAccounts.js

Two parallel data paths producing identical account shapes. App.jsx picks: hasLocalData ? localAccounts : uploadedAccounts
useLocalData.js (Vite dev server — polls /local-data/manifest every 5s) 1. Fetches CSV file list from data/ folder 2. Detects table type from filename or column headers 3. Calls parseCSV() for each file 4. Groups records by customer_account 5. Calls buildAccountState() per account 6. Maps into final account object: useAccounts.js (Browser upload — drag-and-drop or file picker) 1. Reads FileList from drop/input event 2. Same detect + parse + build pipeline 3. Identical output shape FINAL ACCOUNT OBJECT (both paths): { id: index, name: customer_account, arr: total_arr, from customers.csv total_brr mrr: total_mrr, = arr / 12 pipeline_mrr: active_pipeline_mrr, risk_score: 0..100, rep: primary_rep, from customers.csv manager: account_manager, sales_owner: sales_owner, from customers.csv active_deals: [ from funnel.csv, stage NOT closed { product, mrr, stage, forecast: forecast_category, close: close_date, rep: rep, opportunity_id, sales_channel, created, major_project, icb, icb_id } ], funnel_closed: [ from funnel.csv, stage = closed won/lost { product, mrr, stage, type, close, rep, opportunity_id, sales_channel, created, forecast: forecast_category, major_project } ], historical_deals: [...], for modeling ONLY locations: [...], losses: { deals, disconnects, downgrades, ... }, ... }

5. Dashboard KPI Formulas

5a. Seller Dashboard (RepDashboard.jsx)

Filters deals by Opportunity Owner (d.rep field) — NOT Account Sales Owner. Source: funnel.csv ONLY.
DATA SETUP: allActiveDeals = accounts.flatMap(acc → acc.active_deals.filter(d.rep === selectedRep)) funnelClosed = accounts.flatMap(acc → acc.funnel_closed.filter(d.rep === selectedRep)) allFunnelDeals = [...allActiveDeals, ...funnelClosed] combined for bookings calc BOOKING FILTER: isBooking(d) = normalizeForecast(d.forecast) === 'Closed' forecast_category must be "Closed" AND !d.major_project major_project must be blank/empty AND d.mrr > 0 positive MRR only FORECAST NORMALIZATION: "closed", "closed won" → "Closed" "commit" → "Commit" "best case" → "Best Case" "longshot" → "Longshot" anything else → "Not In Forecast"
YTD Bookings
SUM(mrr) WHERE isBooking(d) AND close_date in [Jan 1 .. Dec 31]
Source: allFunnelDeals (active + closed from funnel.csv)
QTD Bookings
SUM(mrr) WHERE isBooking(d) AND close_date in [Q start .. Q end]
Source: allFunnelDeals | Full quarter (not truncated to today)
MTD Bookings
SUM(mrr) WHERE isBooking(d) AND close_date in [month start .. month end]
Source: allFunnelDeals | Full month (not truncated to today)
Quota Attainment
periodBookings / periodQuota
periodQuota = userTarget || rep_profiles.q{N}_quota || annualQuota/4
monthlyQuota = quarterlyQuota / 3
Pace to Quota
periodBookings / expectedPeriod
expectedPeriod = periodQuota * (dayOfPeriod / daysInPeriod)
Green: ≥100% | Yellow: 75-99% | Red: <75%
Pipeline Coverage
weightedPipeline / targetRemaining
weightedPipeline = SUM(d.mrr * stageProb(d.stage))
targetRemaining = MAX(0, periodQuota - periodBookings)
Stage probs: Discover 30.57%, Design 53.21%, Propose 66.23%, Negotiate 84.67%, Verbal 92.49%
Book of Business
SUM(acc.arr) for repAccounts
Source: customers.csv total_brr | repAccounts = accounts where sales_owner === rep
Win Rate
closedWon / (closedWon + closedLost)
Source: funnelClosed only | Excludes major_project & negative MRR

5b. Forecast Dashboard (ForecastDashboard.jsx)

Filters to Premier channel only (sales_channel = 'Premier'). Aggregates across ALL accounts.
Total MRR (Period)
SUM(mrr) WHERE isBooking(d) AND close in period
Same isBooking filter as Seller Dashboard
YTD Bookings
SUM(mrr) WHERE isBooking(d) AND close in year
Source: allFunnelDeals (Premier only)
Weighted Pipeline
SUM(d.mrr * stageProb(d.stage)) WHERE active deals, no major_project, mrr > 0
Uses same stage win probabilities as Seller Dashboard
MRR Trajectory
By month: raw = SUM(mrr), forecast = SUM(mrr * stageProb)
Closed deals use actual MRR; open deals use weighted MRR
Quarterly Net New MRR
booked = SUM(mrr*12 WHERE mrr>=0)
churn = SUM(|mrr|*12 WHERE mrr<0)
net = booked - churn
Per quarter from closedWonDeals (annualized to ARR)
Win Rate Trend
Per quarter: closedWon / (closedWon + closedLost)
Excludes major_project deals
Bookings by Type
New Logo | Expansion | Renewal | Other
Grouped by quarter, values = mrr * 12
Type mapping: 'new'→New Logo, 'expansion/re-rate'→Expansion, 'renewal'→Renewal
Deal Size Distribution
Buckets: <$1K, $1-5K, $5-10K, $10-25K, $25-50K, $50K+
Count of deals per bucket (ARR = mrr*12)
Separate bars for Closed (YTD) and Pipeline (open)

6. Critical Data Rules

RuleDetail
Bookings Sourcefunnel.csv ONLY. Never from historical.csv. Combined from acc.active_deals + acc.funnel_closed.
ARR Sourcecustomers.csv total_brr field ONLY. Summed if multiple rows per account. Services MRR is context only.
Rep AttributionBookings filter by Opportunity Owner (d.rep), NOT Account Sales Owner. Book of Business uses acc.sales_owner.
Booking Filterforecast_category = "Closed" AND major_project = blank AND mrr > 0. No stage check needed.
MRR vs ARRSeller Dashboard shows MRR (monthly). Forecast Dashboard converts to ARR (mrr * 12) for some charts.
Period BoundariesQTD/MTD use full period (e.g., Mar 1 - Apr 1), not truncated to today.
Channel FilterForecast Dashboard filters to Premier channel only. Seller Dashboard has no channel filter.
ChurnClosed Won deals with negative MRR are classified as churn, not bookings.
historical.csvUsed for backtest, learning curves, and calibration ONLY. Never for bookings or current KPIs.
